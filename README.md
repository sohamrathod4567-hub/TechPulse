# TechPulse

**An AI-powered Technology Job Market Intelligence Platform**

## Overview

TechPulse is a data-driven platform designed to collect, process, and analyse technology job listings across different markets, initially focusing on France and India.

The platform aims to identify hiring trends, in-demand technical skills, emerging technologies, and employment opportunities.

It will also incorporate resume analysis and intelligent job-matching capabilities.

## Planned Features

- Job listing collection and aggregation
- Job market trend analysis
- In-demand skills identification
- Geographic hiring insights
- Resume skill extraction
- Intelligent job matching

## Technology Stack

- Python
- Pandas
- PostgreSQL
- SQLAlchemy
- FastAPI
- Streamlit
- Scikit-learn
- Docker
- Git & GitHub

## Project Architecture

Job Collection → ETL Pipeline → PostgreSQL → FastAPI → Analytics & Job Matching → Streamlit Dashboard
